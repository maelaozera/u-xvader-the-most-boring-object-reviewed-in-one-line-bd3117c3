## The entry

A one-line review of the dullest everyday object imaginable: the doorstop.
A rubber wedge whose entire career is being kicked and stepped on — and which
still loses to a light breeze. The joke comes from how the object really
behaves, and the last words sharpen it. 119 characters, one line, well inside
the 200-character gate.

## How to run

Requires Node 22 or later (no dependencies):

```sh
node main.ts
```

This writes the review to `/output/entry.txt` and prints its character count.
`main.ts` self-checks the gate before writing: 1–200 characters, a single
line, not only whitespace.
